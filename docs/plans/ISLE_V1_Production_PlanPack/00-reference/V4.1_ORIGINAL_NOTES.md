# ISLE V4.1 · 自适应等高摄影墙

直接打开 `index.html` 即可。默认已采用 Justified Gallery。

## 修改点
- 地点首页的第 02–04 名和完整榜单不再使用等宽三列/两列。
- 每一行自动计算等高图片的不同宽度，**不裁切、不拉伸、不重排名次**。
- 对照片比值与视口宽度进行分组优化，避免单独竖图撑开整行。
- 竖图较窄时，照片标题和投票自动换成两层布局。
- 手机上维持单列，照片仍按原始比例显示。
- 仍使用原 V4 的投票、灯箱、地点、上传等交互。

## 预览素材说明
为便于在离线 HTML 中直接看见你截图里的版式，第 02–04 名的列表缩略图采用你提供的网页截图局部截取，只有网页预览分辨率。原图灯箱的示例照片仍使用原 V4 定义的 Wikimedia Commons 原始 URL；截图缩略图**不代表原图画质**。其余测试图片保持原 V4 的外部资源。正式开发需要按用户上传的原始 w/h 计算布局，同时灯箱独立加载真正原文件。

## 算法
`bestPhotoRows` 以维持排名顺序为硬约束，动态规划优化每行照片数量和行高；`renderPhotoWall` 根据原始图片长宽比设置每张的宽高，通过 flex 保证整行对齐。
